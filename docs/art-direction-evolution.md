# VAKVORM — Art Direction Evolution

From restrained editorial to a warmer, more colourful, more commercially alive premium
brand — without becoming a contractor template or copying the supplied reference. Structure,
IA, URLs, content model, ServiceIndex interaction and typography families are unchanged.

## 1. Why the previous design felt dusty
- The canvas was one cool, dusty beige, dominating ~90% of the page.
- Rhythm was beige → beige → beige → near-black → beige: little chapter contrast.
- Every media well was the same pale tone — "two pale rectangles on a pale background."
- Thin hairlines carried too much design responsibility; too much pale empty space with no
  focal anchor per viewport. The accent had been almost fully removed → no warmth or energy.

## 2. Principles taken from the references (atmosphere, not components)
- **Deep navy** for confidence, depth and chapter separation.
- A **warm accent** for action and warmth (theirs is gold; ours is earthier).
- **Strong section contrast** — scrolling visibly moves through chapters.
- **Photography-led emotion** (designed for; images pending).
- **Commercial confidence** — obvious, warm calls to action; visible trust.

## 3. Explicitly rejected from the references
Heavy card usage, badge/utility bars, "known from TV" / 5-star widgets, Google-review
components, icon/illustration benefit cards, TV promotion, rounded-rectangle clutter, bright
gold + corporate navy branding, visual busyness. No fabricated numbers/ratings/awards.

## 4. New palette & distribution
| Token | Value | Role | ~share |
|---|---|---|---|
| `--ivory` / `--bone` | `#f3efe4` | fresher warm-white canvas | ~55% light |
| `--stone` / `--sand` | `#e5ddcc` | warm supporting chapters (trust, interieur, process) | |
| `--navy` / `--deep` | `#16273c` | deep architectural navy — major chapters, gravitas, trust | ~22% |
| `--oxide` | `#b1552d` | burnt sienna / cognac — action & material warmth | ~13% accent |
| `--oxide-warm` | `#c66f42` | on-navy accent / hovers | |
| `--on-ink` / `--on-ink-soft` | cream / muted blue-grey | text on navy | |

Colour is compositional, never decoration: **navy = chapter/gravitas/trust · clay = action/
material · ivory = breathing canvas · stone = quiet supporting chapter.**

## 5. Homepage rhythm now
ivory hero → **stone** trust strip → ivory work → **navy** Bouw & Renovatie band → **stone**
Interieurbouw band → **navy** brand principle → ivory ServiceIndex → **stone** proces → **navy**
"Plannen om te verbouwen?" intake → navy footer. Each major viewport has a focal anchor.

## 6. Surface rules
- Two disciplines are now **distinct colour-field chapters**: Bouw on navy (structural,
  architectural weight), Interieurbouw on stone (material, tactile) — clearly one brand.
- Media wells deepened to stone so they read as *present media*, not empty pale rectangles.
- Statement stays the strongest dark moment, evolved from near-black to **deep navy**, with a
  single cognac word ("één") — not half the text orange.

## 7. CTA rules
Conversion actions are **warm clay, filled, softly rounded (6px)** with a restrained arrow —
inviting and desirable. Primary ≫ secondary (secondary stays a quiet ghost). Hero primary
invites contact. No pills, glow, gradients or oversized shadows.

## 8. Card / container rules
Cards allowed **only for a real object/action** (trust-fact row, contact intake). They are not
the layout grammar — most of the page is still type + space + colour fields + hairlines. No
four-identical-card rows, no icon cards.

## 9. Mobile rhythm rules
Full-width navy/stone/ivory chapters stack edge-to-edge, so mobile moves through immersive
colour chapters instead of one flat pale column. CTAs and the intake read as strong blocks.

## 10. Trust / conversion rules
Integrated, non-fabricated: the trust strip (één aanspreekpunt / complete begeleiding / heldere
planning / hoogwaardige afwerking) and the navy intake with a fact row (werkgebied / twee
disciplines / één aanspreekpunt). Real reviews/credentials slot in later; nothing invented.

## Refinement Pass — Pillar Balance & Commercial Hierarchy

Refinement of the approved evolution (no redesign; hero, typography, IA, ServiceIndex,
navy statement all protected).

### How Interieurbouw was elevated (pillar equality)
Previously Bouw got a strong navy chapter while Interieurbouw fell back to a pale neutral —
accidentally reading Bouw = primary, Interieur = secondary. Now the two are **equal but not
identical specialist worlds**:
- **Bouw & Renovatie** — deep **navy** field, broad/architectural, single landscape media, service list.
- **Maatwerk Interieurbouw** — new warm **material** surface, tactile/editorial, a **two-image
  composition** (large 4:5 + overlapping 1:1 detail), its own sub-service list (maatwerkkasten /
  interieur op maat / wandmeubels) and material-led copy (hout, fineer, verbindingen).
The scroll now reads: navy Bouw → material Interieur → navy one-party principle = **build +
interior = one party.**

### New material surface treatment
Added `--material` (#ddcdb2, warm mushroom/oatmeal — plaster/oak/stone) + `--material-line`
and an `.on-material` surface. Distinct from stone/ivory; evokes interior materiality, not
pink/peach/fashion-beige.

### Primary CTA rule (permanent)
**Warm clay/cognac (`--oxide`) = primary action.** Applied systematically: header "Offerte
aanvragen", hero "Vrijblijvend kennismaken", and the intake CTA are all filled clay (cream
text, 6px radius, hover → ink). Clay stays scarce enough to *mean* "take action".

### Secondary/tertiary CTA rule (permanent)
- **Secondary** = neutral **outlined** button (hero "Onze werkwijze").
- **Tertiary** = typographic **arrow/underline link** ("Alle projecten", "Volledige werkwijze",
  "Naar interieurbouw", "Meer informatie"). Never competes with the clay primary.
Accent discipline: clay only on primary CTAs, active/selected states, the single statement word,
and small interaction feedback — not on section labels, static numbers, or decoration.

### Selected Work composition
Fewer, larger, more confident: one large primary media (~68%) with an offset secondary, less
pale empty space, media wells deepened to stone so they read as *present* proof. Designed so a
real Dutch renovation + a bespoke-interior detail will read as important. No cards/shadows/tiles.

### Werkwijze
Lifted from a footer-like 4-column row to a chapter with presence: a lead statement + a
**process-image position** (future site/craft photography) alongside four large numbered steps
with a connecting rhythm. Communicates control, planning, coordination, accountability.

### Trust strip
Bigger titles (1.3rem), more vertical air, **column borders removed** (less spreadsheet), cleaner
rhythm. Still factual reassurance — no icons, no cards.

### Mobile
Full-width navy/material/stone chapters stack edge-to-edge → the two pillars read as distinct
immersive worlds; Werkwijze keeps large stacked steps (not tiny columns); the clay primary CTA
is obvious throughout.
