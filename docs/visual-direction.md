# Visual direction

**Superseded.** The visual system is now the NEDERDAM brand identity — see
[`brand-identity.md`](brand-identity.md) for tokens, typography, layout, UI and photography
rules, and `src/app/globals.css` for the implementation.

The earlier direction (navy + clay, Public Sans + IBM Plex Mono, the datum-line marker
system) informed the site's structure and copy discipline, and its rules on restraint still
hold:

- No component-library aesthetics, no cards-for-everything, no equal-height grids.
- No fabricated content: reviews, statistics, projects and addresses appear only when real.
- Motion follows content and never runs on every element.
- The site must never advertise that software built it — see
  [`anti-ai-audit.md`](anti-ai-audit.md).

Everything about colour, type and composition in the older documents in this folder
(`design-review-01.md`, `typography-review.md`, `homepage-recomposition.md`,
`art-direction-evolution.md`, `visual-merge-review.md`) describes the previous system and is
kept as history.
